# Cloud-Based Food Delivery Application

## Project Overview
This project is a cloud-based food delivery application developed using Flask and MySQL.

## Features
- User Registration
- User Login
- Password Hashing
- Food Menu
- Order Placement
- Order History
- Session Management

## Technologies Used
- Python Flask
- MySQL
- HTML
- Bootstrap
- AWS EC2
- Gunicorn
- Nginx

## Security Features
- Password Hashing
- Session Management
- Secure Authentication
